# Polygon agent facilitator

The user selected Polygon PoS mainnet (137 / `eip155:137`). MetaMask device acceptance will be performed later by the user. The code accepting Polygon is separate from proof of a live purchase.

Use the manifest generated by EC's `packages/agent-commerce/scripts/polygon-deployment.mjs manifest`. The same manifest is used by both repositories. It pins the actual deployed Gate, Adapter, Validator, official Manager/account/enforcers, JPYC/native USDC proxies and implementations, and Uniswap router/factory. Both tokens require implementation pins. Circle USDC uses its custom proxy slot, not the EIP-1967 default.

Set `AGENT_COMMERCE_ENABLED=true`, `AGENT_DEPLOYMENT_MANIFEST`, `AGENT_RPC_URL`, `AGENT_RELAYER_PRIVATE_KEY`, `AGENT_JOURNAL_PATH`, `AGENT_EC_ORIGIN`, `AGENT_EC_KEY_ID`, `AGENT_EC_HMAC_SECRET`, and `FACILITATOR_HMAC_KEYS`. The public-chain relayer key must match the shared manifest and must differ from the legacy EIP-3009 key. Fund its gas with POL; keep the SQLite journal on persistent storage. Node 22.14+ is required. Worker agent execution remains disabled.

The default legacy RPC configuration does not configure this agent path. Use a validated Polygon HTTPS endpoint. EC's read-only preflight compares two RPC providers, implementation slots and 100/1,000/10,000 JPYC exact-output quotes. Those quotes must be refreshed at purchase time.

After device permission acceptance and the EC integration are ready, start with one 100 JPYC purchase, then the user-approved 1,000 JPYC × 10 sequence. Match both PurchasePaid and JPYC Transfer to the EC order. Record actual USDC input, gas, confirmation time and recovery. A lost broadcast response must recover the same stored raw transaction; unknown status is never proof of nonpayment.

The business budget OR an exact-order approval from the registered person remains unchanged, including period-budget overrun. Expiry, revocation, tampering and signature/approval replay stay non-overridable. This document does not claim deployment, wallet acceptance, World/Intercepta acceptance or live purchases.
